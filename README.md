# 🚀 dio-gemini-notebook: Fundamentos de Programação e Arquitetura de Software

Este repositório reúne anotações, mapas mentais, apresentações e fontes de estudo estruturadas com o auxílio do **NotebookLM (Gemini Notebook)**. O objetivo é servir como um roteiro prático e direcionado para quem deseja aprender desde os conceitos mais fundamentais de programação até princípios sólidos de arquitetura de software.

---

## 📌 Contexto e Metodologia

Para estruturar esta base de conhecimento, selecionamos canais renomados e didáticos na comunidade de tecnologia — amplamente reconhecidos pelo feedback positivo e foco no aprendizado de iniciantes:

- **Curso em Vídeo**: Referência em didática inicial para lógica de programação e bases da computação.
- **Bóson Treinamentos**: Conteúdos aprofundados sobre fundamentos de computação, lógica, algoritmos e boas práticas.
- **Sharpx**:Focado em ensinamentos para iniciantes e intermediários com muitos comentários positivos.
- **A Dev' Story**: Abordagens práticas de arquitetura, padrões de projeto e desenvolvimento de software.

Foram incorporados artigos e documentações técnicas selecionadas por meio do **Deep Research**, garantindo um direcionamento atualizado.
